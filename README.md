# SHUICENG · 税层

> 我的税法学习笔记。

税层是一个面向税法学习者的开源笔记组织，致力于把税法知识从“零散条文”整理成“可检索、可复用、可讨论”的学习资料。我们相信：税法不只是背法条，更是理解规则背后的逻辑，并在真实场景中准确应用。

**主题：税法 · 学习 · 应用**

## 📚 我们在做什么

- **系统化笔记**：按税种、程序、实务专题组织学习笔记，避免碎片化。
- **开源协作**：所有笔记以 Markdown 形式维护，欢迎提交 Issue 和 Pull Request。
- **学以致用**：每个专题尽量配案例、计算示例和常见误区，帮助从“看懂”到“会用”。
- **持续更新**：税法政策变化快，笔记会随法规更新而迭代，并保留修订记录。

## 🗂️ 笔记分类

| 分类 | 内容示例 |
| --- | --- |
| 税法基础 | 税收法律关系、税法原则、税制结构 |
| 增值税 | 征税范围、税率、进项抵扣、发票管理 |
| 企业所得税 | 应纳税所得额、扣除项目、税收优惠 |
| 个人所得税 | 综合所得、专项附加扣除、汇算清缴 |
| 小税种 | 印花税、房产税、契税、城建税等 |
| 税收征管 | 纳税申报、税务稽查、行政复议 |
| 实务案例 | 计算示例、争议分析、学习问答 |

## 🧭 怎么使用

1. **按需浏览**：从上方分类进入对应仓库或目录，先看目录再读正文。
2. **搜索关键词**：使用 GitHub 搜索 `org:SHUICENG 关键词` 快速定位笔记。
3. **带着问题学**：建议先看“常见误区”和“案例”，再回到法条和原理。
4. **参与讨论**：对内容有疑问或补充，欢迎在对应仓库提 Issue。

## 🤝 如何贡献

- 提交 **Issue**：指出错误、补充案例、建议新专题。
- 提交 **Pull Request**：修正笔误、完善笔记、增加示例。
- 贡献原则：**准确、简洁、可验证**；引用法规请注明文件名称和条款。
- 笔记格式：统一使用 Markdown，标题层级清晰，代码块/表格按需使用。
